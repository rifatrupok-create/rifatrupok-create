# Portfolio typography

Manrope (variable, weights 200-800) and Instrument Serif (regular and italic) are hosted locally. The font files are redistributed under the accompanying SIL Open Font License files. No external font request is made when a visitor loads the portfolio.

Sources:
- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/instrumentserif

The résumé uses embedded Arial for dependable text extraction and a traditional recruiting format.
